# Mikatox Stream Hub — téléchargement

**Mikatox Stream Hub** est le poste de commande du streamer : chat Twitch fiable, alertes, contrôle d'OBS, lumières (Bluetooth et Wi-Fi), voix et sons, Stream Deck, et un deck pour tablette ou téléphone.

Ce dépôt contient **uniquement les installateurs**. Application gratuite de **Mikatox TV** ; copie, modification ou revente interdites sans autorisation.

## Télécharger

1. Ouvre la page **[Releases](../../releases/latest)** (à droite sur cette page).
2. Télécharge le fichier `…_x64-setup.exe` de la dernière version.
3. Lance-le. Windows peut afficher « Windows a protégé votre ordinateur » (l'installateur n'est pas encore signé) : clique sur **Informations complémentaires**, puis **Exécuter quand même**.

L'app te prévient toute seule quand une nouvelle version est disponible ; tu décides d'installer ou non.
